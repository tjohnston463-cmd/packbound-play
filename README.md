# Packbound

Playable build of the hunt. Open the site, pick a calling, and press New Hunt. The Wildcaller is the druid. The Gravecaller is the necromancer. The Stormbinder is the sorceress. Each wave grows a grove shrine you walk into. At camp, Gamble spends Dust on a real drop.

The private source stays in Packbound. This repo is only the files the browser needs.
