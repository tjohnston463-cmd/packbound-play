# Packbound

Playable build of the hunt. Open the site, pick a calling, and press New Hunt. Six callings: the Wildcaller, the Gravecaller, the Stormbinder, the Oathbound, the Skymark, and the Warbound. Each has its own pack and its own weapon.

After the first clear, one open wood is the Terror. It is marked in red. It is harder, and it pays better. Four Dust calls it onto the next wood. Your own hits can crush a tough body, strike twice, and return life or Spirit. The belt holds flasks. Z, X, and B drink.

The private source stays in Packbound. This repo is only the files the browser needs.
